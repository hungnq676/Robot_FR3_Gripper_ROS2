TABLE Bảng 0.1. Danh mục từ viết tắt
| Viết tắt | Tiếng Anh | Giải thích tiếng Việt |
| --- | --- | --- |
| AI | Artificial Intelligence | Trí tuệ nhân tạo |
| API | Application Programming Interface | Giao diện lập trình ứng dụng |
| DOF | Degrees of Freedom | Số bậc tự do |
| ESP32 | – | Vi điều khiển có Wi-Fi của hãng Espressif |
| FK | Forward Kinematics | Động học thuận |
| HTTP | Hypertext Transfer Protocol | Giao thức truyền siêu văn bản |
| IK | Inverse Kinematics | Động học ngược |
| IPPE | Infinitesimal Plane-based Pose Estimation | Ước lượng tư thế từ mặt phẳng |
| LOO | Leave-One-Out | Kiểm tra chéo bỏ ra một mẫu |
| MTC | MoveIt Task Constructor | Bộ dựng tác vụ của MoveIt |
| PnP | Perspective-n-Point | Bài toán tìm tư thế từ n điểm ảnh |
| PTP | Point-To-Point | Chuyển động điểm tới điểm trong không gian khớp |
| RANSAC | Random Sample Consensus | Thuật toán đồng thuận mẫu ngẫu nhiên |
| RGB-D | Red Green Blue – Depth | Ảnh màu kèm ảnh độ sâu |
| RMS | Root Mean Square | Căn bậc hai trung bình bình phương |
| ROS 2 | Robot Operating System 2 | Hệ điều hành robot thế hệ 2 |
| RViz | ROS Visualization | Công cụ hiển thị 3D của ROS |
| SAM | Segment Anything Model | Mô hình phân vùng mọi đối tượng |
| SDK | Software Development Kit | Bộ công cụ phát triển phần mềm |
| TCP | Tool Center Point | Điểm làm việc của dụng cụ |
| TF | Transform | Cây biến đổi hệ toạ độ của ROS |
| VLA | Vision-Language-Action | Mô hình thị giác – ngôn ngữ – hành động |
| UART | Universal Asynchronous Receiver-Transmitter | Giao tiếp nối tiếp không đồng bộ |
| URDF | Unified Robot Description Format | Định dạng mô tả robot |
| YOLO | You Only Look Once | Họ mô hình phát hiện vật thể một giai đoạn |
