chạy con cánh tay robot FR3

bước1 khỏi tại môi trường và chạy spawner: 
	- vào foder ros2_ws: cd ros2_ws
	- khỏi tạo môi trường cho ros: source /opt/ros/humble/setup.bash
	- khỏi tạo môi trường cho robot: source ~/ros2_ws/install/setup.bash
	- chạy lệnh chạy spawer:
		 ros2 launch fairino3_v6_moveit2_config spawn_controllers.launch.py

bước2 chạy moveit2 lên: mở 1 cái terminal mới 
	- chạy các khợi tạo cần thiết
	- chạy cái lệnh chạy moveit2:
		ros2 launch fairino3_v6_moveit2_config demo.launch.py

bước3 kết nối với robot fr3:
	- mở terminal mới
	- chạy mấy lệnh khởi tạo
	- chạy lệnh kết nối với robot:
		ros2 run fairino_hardware ros2_cmd_server
